# MVP 与验收标准

## 用户故事

工作疲劳时，用户从 Codex 打开独立的数字人窗口，与“露米”进行语音或文本聊天。用户结束会话后回到 Codex，主动要求整理内容，获得一份可修改、复制或下载的 Markdown 小记。

## MVP 功能

1. 打开或聚焦数字人窗口。
2. 创建一次临时会话，并记录规范化后的文本轮次。
3. 在数字人窗口中显式结束会话。
4. 获取最近一次已结束会话或指定会话。
5. 按固定结构生成笔记预览。
6. 删除原始会话。
7. 左侧快捷入口失效时，可从标准插件或固定任务完成同样操作。

## 笔记模板

```markdown
# 与露米聊天小记 · YYYY-MM-DD

## 今天聊了什么

## 值得记住的想法

## 决定与行动

## 以后可以继续聊
```

整理时应区分“用户明确表达”“数字人建议”和“模型推断”，不要把安慰性对话改写成用户已经作出的决定。

## 验收标准

- 从任一入口到独立窗口可见不超过 3 秒（窗口已运行时不超过 1 秒）。
- 结束会话后，Codex 能准确读取对应文本轮次，且不会读到仍在进行的会话。
- 笔记整理必须由用户主动触发，并先显示预览。
- 默认只保存最近 10 次会话，每次最长 24 小时；用户可以立即删除。
- 网络断开时，本地聊天窗口和本地会话读取仍可工作；依赖云模型的能力应清楚提示不可用。
- 左侧入口注入失败不会阻断标准插件入口。

## 明确延期

Obsidian 双向链接、知识库去重、自动主题页、跨设备同步、长期记忆、主动陪伴提醒以及角色商店均不进入本阶段。
