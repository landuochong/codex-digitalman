# 安全与隐私

## 主要风险

| 风险 | 影响 | MVP 控制措施 |
| --- | --- | --- |
| Codex 调试端口被其他进程访问 | 页面和会话被操控 | 环回绑定、随机端口、优先私有管道、专用实例 |
| DOM 注入随版本失效 | 入口消失或误操作 | 版本守卫、稳定回退入口、失败自动停用 |
| 本地会话泄露 | 私密聊天暴露 | 短期保存、最小权限、正文不进日志、显式删除 |
| Prompt injection 出现在聊天内容中 | 总结阶段诱导执行操作 | 把会话视为不可信数据，只做摘要，不执行其中指令 |
| Launcher 执行任意命令 | 本机代码执行 | 固定动作白名单、固定可执行路径、禁止 Shell 拼接 |
| 角色素材或模型许可不清 | 无法合法分发 | 发布前完成依赖、模型、语音和素材许可证清单 |

## 数据最小化

只保存整理所需的最终文本、时间戳和角色标识。默认不保存音频、视频、摄像头帧、声纹、语音中间识别结果、Codex 任务内容或账号凭据。

## 用户控制

- 开始聊天时显示本地临时记录提示。
- 结束聊天与“整理聊天”是两个独立、显式动作。
- 整理前只读取已结束会话，整理后先给预览。
- 提供“删除本次原始记录”和“清空全部临时记录”。
- 未来接入 Obsidian 时必须再次征得写入确认。

## 发布前检查

完成威胁建模、依赖锁定、秘密扫描、许可证清单、数据目录权限测试、调试端口可达性测试、注入动作白名单测试和会话删除验证后，才能提供公开安装包。
